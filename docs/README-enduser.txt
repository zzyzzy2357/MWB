度量衡 · MWB  v2.26.1
========================================

一、怎么启动
  1. 把压缩包完整解压到一个固定目录（例如 D:\MWB）
     不要只把 MWB.exe 拖出来：同目录的 DLL、runtimes、wwwroot 都是必需的
  2. 双击 MWB.exe
  3. 若提示缺少 WebView2，安装一次微软的 WebView2 Runtime：
     https://developer.microsoft.com/microsoft-edge/webview2/

二、第一次使用
  1. 右上角「+ 添加站点」，填中转站地址（如 https://api.example.com）
     也可以「导入 → 云端站点库」一键拉取社区维护的站点清单，不用一个个手输
  2. 需要账号才能看的价格：点站点卡片上的锁图标登录，登录后会自动记住账号密码
  3. 点「开始比价」，等进度条跑完
  4. 点模型右侧「详情」，可以看到各站报价、显示充值价与真实价格

三、数据存在哪
  %LOCALAPPDATA%\MWB
    app.db            站点、设置、密钥（密码与 Cookie 用 Windows DPAPI 加密）
    official-prices   官方价缓存
  「设置 → 打开数据目录」可以直接跳过去。
  整个目录复制走可以备份；换电脑后加密内容需要重新登录或重填密码。

四、云端站点库（可选）
  软件本身不带任何站点数据，初始是空列表。
  「设置 → 云端站点库」已预填社区清单地址，直接「导入 → 云端站点库」即可拉取；
  也可以换成自己或别人维护的地址，支持填多个，按域名去重。
  想分享自己在用的站点：站点编辑窗左下角「分享到公共站点库」，
  只提交名称、地址、类型、充值比例四项，不含任何账号密码。

五、常见问题
  · 抓取失败：先点「重新抓取失败站点」；长期不用的站可以在左侧隐藏或禁用
  · 显示「需登录」：本地 Cookie 只剩匿名的，点一次登录即可
  · 价格显示「<0.0001」或「—」：该站倍率写错，软件已判定为无效价格
  · 杀毒软件误报：单文件 exe 常被启发式误杀，可加入信任或提交到 VirusTotal 自查
  · 云端清单里的站：只代表「当时能访问」，价格与资金安全请自行判断，建议小额测试

六、隐私与免责
  软件只在本机读写数据，不上传任何站点、账号或密钥，没有账号体系，也没有遥测。
  「分享到公共站点库」只提交站点名称、地址、类型、充值比例，不含凭据。
  本软件不提供中转站服务，也不参与交易；站点质量与资金安全请自行判断，建议小额测试。
